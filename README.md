# محاسبه‌گر دوز کاستیک و کربنات سدیم

اپلیکیشن وب یک‌فایلی (بدون نیاز به نصب برنامه، بک‌اند یا اینترنت پس از بار اول) برای محاسبه نرخ تزریق Na₂CO₃ و NaOH در تانک رسوب‌دهی آب‌نمک واحد کلر-آلکالی، بر اساس دفترچه راهنمای بهره‌برداری (سند `8408205-CB-PR-MNL-0102`).

فایل اصلی: [`index.html`](./index.html) (نسخه‌ی یکسان در [`outputs/dosing-calculator.html`](./outputs/dosing-calculator.html) هم نگه‌داری می‌شود).

## انتشار روی GitHub Pages

1. این مخزن را در GitHub پوش کنید.
2. در تنظیمات مخزن: **Settings → Pages → Build and deployment → Source: Deploy from a branch**، سپس شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
3. بعد از چند دقیقه، آدرسی مثل `https://<username>.github.io/<repo>/` فعال می‌شود.

## نصب روی آیفون (Add to Home Screen)

1. آدرس صفحه‌ی منتشرشده را در **Safari** آیفون باز کنید (نصب فقط از طریق Safari ممکن است، نه مرورگرهای دیگر).
2. دکمه‌ی **Share** (مربع با فلش رو به بالا) را بزنید.
3. گزینه‌ی **Add to Home Screen** را انتخاب کنید و تأیید کنید.
4. آیکون اپ روی صفحه‌ی اصلی گوشی اضافه می‌شود و با زدن آن، اپ به‌صورت تمام‌صفحه و مستقل از نوار آدرس سافاری باز می‌شود.

این اپ کاملاً آفلاین کار می‌کند (تمام کد و منطق داخل همان یک فایل HTML است)؛ فقط فونت فارسی Vazirmatn از CDN بارگذاری می‌شود و در نبود اینترنت با فونت پیش‌فرض سیستم جایگزین می‌شود.
